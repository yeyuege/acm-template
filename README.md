# ACM 算法模板

个人算法竞赛（ACM / ICPC）模板库，收集常用算法与数据结构的 C++ 实现。

所有模板集中在 [template.md](template.md)，按分类组织，方便查找与复制。

## 内容概览

| 分类 | 内容 |
| --- | --- |
| **基础** | 主模板（头文件 + IO + 调试宏）、快读、I128、pb_ds、Python 模板 |
| **数学** | 数论（欧拉筛、exBSGS、CRT、Lucas、杜教筛、Min_25 筛、二次剩余）、多项式（NTT、Poly）、线性代数（矩阵、高斯消元）、数值方法（辛普森积分、拉格朗日插值） |
| **数据结构** | 并查集（含可撤销）、树状数组（含二维）、线段树（动态开点、懒标记、合并、分裂、主席树、树套树、李超线段树）、平衡树（FHQ Treap、Splay）、左偏树、线性基、ST 表、珂朵莉树 |
| **图论** | 连通性（SCC、边双、点双、圆方树）、生成树（Boruvka、prufer 序列）、匹配（HK、带花树）、网络流（最大流、费用流、全局最小割）、LCA、树链剖分、虚树、LCT、2-SAT |
| **字符串** | Trie、01Trie、AC 自动机、Fail Tree、KMP、Z 函数、Manacher、最小表示法、SAM、SA |
| **计算几何** | 点线基本函数、三维向量、凸包、旋转卡壳 |
| **莫队** | 普通莫队、带修莫队、回滚莫队、二次离线莫队 |
| **其他** | 随机数/树/图生成、对拍 |

## 使用说明

- 模板默认使用 C++17 及以上标准，编译时建议开启 O2。
- 主模板见 [template.md](template.md) 的 `0.1` 节。
- 不同板子可能依赖不同的全局声明（如 `ll`、`Z` 取模类、筛法数组等），复制时注意把依赖部分一起带上。
